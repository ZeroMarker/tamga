# TAMGA · 草原的印记

游牧文化 tamga 中文数字图录。网站源代码位于 [exhibit](exhibit/README.md)，静态入口为 `exhibit/dist/index.html`。

在线访问：[TAMGA · 草原的印记](https://zeromarker.github.io/tamga/)。

本地预览：`python3 -m http.server 4173 --directory exhibit/dist`。

GitHub Pages 通过 `.github/workflows/pages.yml` 发布 `exhibit/dist`。推送页面更新到 `main` 时自动部署，也可在 Actions 中手动运行。
