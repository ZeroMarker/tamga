# TAMGA · 草原的印记

中文 tamga 数字展览。纯静态 HTML、CSS、JavaScript，无构建依赖。

在此目录运行 `python3 -m http.server 3000 --directory dist`，然后访问 http://localhost:3000。

支持八枚乌古斯部族印记的分组筛选、中文/拉丁族名搜索、详情对话框、键盘导航和当前浏览器收藏。收藏仅保存在 localStorage，没有远程服务。

图样保留 Wikimedia Commons 原始 SVG，详情提供各自的来源页及许可入口。数字图样是文献传统的现代绘制版本，不是文物照片。草原照片：Martin Vorel / LibreShot，CC0，https://libreshot.com/mongolian-steppe-landscape/ 。

内容参考 Encyclopaedia Iranica、The Silk Road 11 (2013) 的《Tamgas, a Code of the Steppes》，以及乌古斯部族分类；页面附有对应阅读链接。
